# SWAPNIL — Portfolio

A responsive personal portfolio showcasing selected web and AI experiments.

## Projects shown
- **THE INDIA** — live travel and culture website: https://the-india.primesgaming7.workers.dev/
- **AI Podcast** — experimental AI podcast game repository: https://github.com/primesgaming7-coder/Ai-Podcast-1
- **ULTRON** — offline AI learning experiment, presented with custom pixel-art preview.

Discontinued FRIDAY and unfinished Student Life OS entries have been removed.

## GitHub live data
The portfolio reads public profile information from the GitHub REST API for `primesgaming7-coder`, including public repository count, followers, following, and total stars across the repositories returned by the API. It refreshes when the page loads, when the browser tab becomes visible, and every five minutes while the page remains open. GitHub's unauthenticated API rate limits may temporarily prevent updates.

## Files
- `index.html` — page structure and content
- `style.css` — responsive styling
- `script.js` — navigation, project filters, GitHub API integration and optional GSAP effects
- `assets/ultron-pixel-art.png` — ULTRON project preview artwork

## Run locally
Open `index.html` in a browser, or serve the folder with a local static web server.

## Before publishing
Replace `YOUR_EMAIL@example.com` in the contact link with the email address you want visitors to use.
